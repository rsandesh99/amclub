# Pre-launch checklist — founder-gated externals

Things only the founder can do, which **enable** features that are already
built and shipped dark. Referenced by `BUILD_PROMPTS.md` ("How to run this
plan" §3), `docs/agents/README.md`, and `docs/COMPLIANCE.md`.

## Track 1 — vendors & credentials

### 1.1 Razorpay live keys + Route
Live `RAZORPAY_KEY_ID/SECRET/WEBHOOK_SECRET`; Route linked accounts per provider
(`set_route_account` in /admin/providers). See `docs/adr/004-*` and
`docs/mart/LAUNCH_RUNBOOK.md`.

### 1.2 MSG91 + DLT
`MSG91_AUTH_KEY`, DLT entity + template registration for transactional SMS.

### 1.3 WhatsApp on Meta's Cloud API (ADR-030; the rails are built, this turns them on)
Setup steps: `docs/agents/WHATSAPP.md`. AMClub talks to Meta directly — no BSP (the Interakt driver is removed).

1. **Meta account (D-WA4).** Create the WhatsApp Business Account **in INR** (the currency cannot be changed later),
   complete business verification, add a dedicated number, and decide which number is the one official AMClub number.
2. **Env (web + runtime):** `WHATSAPP_DRIVER=meta_cloud`, `WHATSAPP_PHONE_NUMBER_ID`, `WHATSAPP_ACCESS_TOKEN`
   (system-user token), `WHATSAPP_APP_SECRET`, `WHATSAPP_VERIFY_TOKEN`, `WHATSAPP_WABA_ID`; optional
   `WHATSAPP_GRAPH_VERSION` (default `v24.0`, format `vNN.0`) and `WHATSAPP_TIMEOUT_MS` (default 10000).
   Web only: `NEXT_PUBLIC_WHATSAPP_NUMBER`. Runtime only: `AGENT_ENABLED=true` (lets the inbound job reply).
   A named driver with a missing credential is reported by the runtime's `/health` (`whatsapp.missing`) and the
   webhook refuses to ingest (503) until it is fixed.
3. **Webhook:** `https://<agent-runtime>/webhooks/whatsapp`, verify token = `WHATSAPP_VERIFY_TOKEN`; subscribe to
   `messages`, `message_template_status_update`, `template_category_update`, `message_template_quality_update`,
   `phone_number_quality_update`, `account_update`, `account_alerts`.
4. **Templates.** Submit every row below, exactly as written (name, language, category, body, button). The URL
   button's fixed prefix is `https://amclub.in/` with one dynamic suffix `{{1}}`. **Telugu and Tamil bodies are
   machine drafts: have a native speaker review them before submitting.** The list is generated from the registry —
   regenerate it (`pnpm --filter @amclub/agent-core templates:list > /tmp/t.md`, `--summary` for one line per kind)
   whenever a template changes, and after the notification / system registries (`templates-notify.ts`,
   `templates-system.ts`) gain kinds.
5. **Migration 0086** applied after the deploy (the code runs without it on the pre-ADR-030 rules until then).

   then flip `agents_enabled.payout_dossier`.

   to receive the one-tap there too.

`AGENT_RUNTIME_URL`; LLM key. Then `AGENT_ENABLED=true` and flip each agent in
`/admin/agents` with a cohort (`docs/agents/RUNTIME.md`).
